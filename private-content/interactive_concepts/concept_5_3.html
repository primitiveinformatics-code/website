Key Insights
Semantic telemetry extends OpenTelemetry spans with custom attributes: llm.faithfulness, llm.hallucination_detected, llm.task_completion. No new infrastructure needed — enrich existing spans.
Sample, don't score everything. LLM-as-judge calls cost tokens. Score 5–10% of production traffic continuously, 100% during incident investigation.
Set thresholds per task type. A creative writing task tolerates lower faithfulness than a medical summary. Semantic SLOs (Service Level Objectives) should be task-specific.
Pair with span context. A hallucination event is far more actionable when you can see the exact prompt, retrieved context, and tool call sequence that preceded it.
