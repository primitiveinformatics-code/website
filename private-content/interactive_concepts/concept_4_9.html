Classify the Memory Type
🎯 Memory Classifier Challenge
For each scenario, choose the correct memory type
💬 An agent recalls that the user prefers concise responses from 3 sessions ago
✅ Episodic! User preferences from past sessions = episodic memory stored in conversation history
📄 An agent searches a vector database of 10,000 product docs to answer a customer question
✅ External! A vector DB of documents accessed via tool call = external memory
⚙️ An agent's system prompt defines: "Always respond in JSON. Use tool X before tool Y."
✅ Procedural! Rules about how to behave / use tools = procedural memory baked into the system prompt
🧠 The LLM knows that Paris is the capital of France (no retrieval needed)
✅ Semantic! World facts baked into model weights = semantic memory
