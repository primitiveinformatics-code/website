Session 5 · Advanced Agents

Multimodal Agents

Agents that perceive and act across text, images, audio, video, and documents — enabling human-level task handling in complex real-world environments

Modality Explorer — What Agents Can Perceive & Generate
👁️ Vision Input / Output
The ability to understand, reason about, and generate images — enabling agents to work with screenshots, diagrams, medical scans, product photos, and more.
  • 📊 Chart & diagram reading — extract data, trends, and structure from visual graphs
  • 🖥️ UI/screenshot understanding — navigate interfaces, fill forms, test web apps
  • 🔍 Object detection & OCR — identify objects, read text from images
  • 🔬 Medical imaging — assist radiologists with X-ray / MRI analysis
  • 🏗️ Spatial reasoning — understand layout, distance, and 3D scene structure

🎙️ Audio Input / Output
Speech recognition (ASR), speaker diarisation, sentiment analysis from voice, and speech synthesis (TTS) — enabling fully voice-driven agent interactions.
  • 🗣️ Speech-to-text — real-time transcription with speaker separation
  • 😊 Emotion detection — identify sentiment, urgency, and stress in voice
  • 🌍 Multilingual audio — transcribe and translate across languages simultaneously
  • 📞 Call analytics — extract action items, topics, and decisions from meetings
  • 🔊 Text-to-speech output — synthesise natural voice responses

📄 Document Understanding
Processing PDFs, spreadsheets, presentations, contracts, invoices, and forms — extracting structured data from unstructured documents at scale.
  • 📋 Table extraction — extract and structure tabular data from PDFs
  • ✍️ Contract analysis — identify clauses, obligations, and risk factors
  • 🧾 Invoice/receipt parsing — extract line items, totals, tax automatically
  • 📑 Form completion — fill structured forms from unstructured source documents
  • 🔗 Cross-document synthesis — reconcile information across multiple documents
Key Tools

Use Case

Use Case
Accounts payable agent reads invoice images → validates against PO → posts to ERP with zero manual data entry
💻 Code + Execution
Generating, executing, and iterating on code within a sandboxed environment — the foundation of computer-use and data-analysis agents.
  • 📝 Code generation — write functions, scripts, and whole applications
  • ▶️ Sandboxed execution — run code safely and observe outputs/errors
  • 🔄 Iterative debugging — read error → fix → re-run until tests pass
  • 📊 Data analysis — load CSVs, run pandas/SQL, generate charts
  • 🖥️ Computer use — control browser/desktop like a human operator

🎬 Video Understanding
Processing temporal visual information — tracking objects over time, understanding actions, monitoring safety conditions, and indexing long-form video content.
  • 🎥 Action recognition — identify what people are doing in video clips
  • ⚠️ Safety monitoring — detect PPE violations, unusual events in CCTV
  • 🏷️ Video captioning — generate timestamped summaries of long videos
  • 📍 Temporal reasoning — answer "what happened before/after X?"
  • 🎞️ Scene segmentation — split video into chapters with semantic labels

Multimodal Agent Challenges
ChallengeDescriptionMitigationDifficulty
Modality AlignmentDifferent modalities may contradict each other (text says "approve", image shows a denied stamp)Conflict detection layer; explicit modality priority rulesHigh
Context Window CostImages/audio consume 100-1000× more tokens than equivalent text descriptionsCompressed vision tokens, audio chunking, selective embeddingMedium
Hallucination in VisionModels can confidently describe objects not present in an imageGrounding checks, confidence thresholds, human-in-loop for high-stakesHigh
LatencyProcessing large images or audio in real-time adds significant latency to agent loopsAsync processing, streaming APIs, cached embeddingsMedium
SecurityImages can carry hidden prompt injections invisible to humans (pixel-level attacks)Image sanitisation, separate visual content classifierHigh
EvaluationHard to write automated evals for "correctly described the chart"LLM-as-judge for visual outputs; human eval rubricsMedium
