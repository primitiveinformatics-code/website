LangGraph — Agents as State Machines

Model agent logic as a directed graph of nodes, edges, and shared state — with cycles, checkpointing, and human-in-the-loop

Why LangGraph?

"LangChain sequences are linear — they break when agents need to loop, branch conditionally, or pause for human input. LangGraph models agent flow as a graph, enabling cycles, conditional routing, and persistent state checkpointing."
🔵

Nodes

Python functions — each is one agent action step

➡️

Edges

Connections between nodes — can be conditional

📦

State

TypedDict shared across all nodes — the memory

🔄

Cycles

Unlike chains — graphs can loop back and retry

💾

Checkpoints

Persist state to resume after failure or pause

🧑‍💻

Human-in-Loop

Pause at any node, await human approval, resume

Checkpointing — Durable Agent Memory

💾

In-Memory Saver

Default. Fast but lost on process restart. Good for development and short tasks.

🗄️

SQLite Saver

Persists to local SQLite file. Survives process restarts. Good for single-server deployments.

🌐

PostgreSQL Saver

Production-grade. Distributed, concurrent, durable. Used in LangGraph Cloud.

⏸️

Human-in-the-Loop

Graph pauses at `interrupt_before=["approve"]`. Human reviews state, resumes with `graph.invoke(None, config)` — continues from exact pause point.

from langgraph.checkpoint.sqlite import SqliteSaver # Create graph with persistent checkpointing with SqliteSaver.from_conn_string("checkpoints.db") as memory: graph = builder.compile( checkpointer=memory, interrupt_before=["submit_code"] # pause for human review ) config = {"configurable": {"thread_id": "task_001"}} # Run until interrupt state = graph.invoke({"messages": [HumanMessage("Fix the auth bug")]}, config) print("Paused at:", state["next_node"]) # "submit_code" # Human reviews... then resume final = graph.invoke(None, config) # resumes from checkpoint
