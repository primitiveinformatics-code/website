The 4 RAGAS Metrics — Click to Explore
🎯
Faithfulness
0.0–1.0
Is the answer grounded in the retrieved context?

Measures: What fraction of statements in the generated answer can be inferred from the retrieved context.

Catches: Hallucinations — answers that add facts not in the context.

score = |verified claims| / |total claims in answer|
🔍
Answer Relevancy
0.0–1.0
Does the answer actually address the question?

Measures: Semantic similarity between the question and answer. Uses reverse-generation — the LLM generates N questions from the answer, then computes similarity to the original.

Catches: Tangential or off-topic answers that are technically grounded but don't answer the actual question.

score = mean(cosine_sim(q, generated_qs))
📚
Context Precision
0.0–1.0
Are the top retrieved chunks actually relevant?

Measures: Ranking quality of retrieval. Are the relevant chunks retrieved at the top positions, or buried below irrelevant ones?

Catches: Noisy retrieval — when the right chunk exists in the DB but gets ranked below irrelevant chunks.

Weighted Precision@k over retrieved contexts
🕸️
Context Recall
0.0–1.0
Did retrieval find all necessary information?

Measures: What fraction of the ground-truth answer's content can be attributed to the retrieved context. Requires reference answer.

Catches: Missing retrieval — when the retriever returns chunks that don't cover all the facts needed to answer.

score = |ground truth sentences supported| / |total ground truth sentences|

Key insight: Faithfulness & Answer Relevancy require no ground truth — RAGAS uses an LLM as evaluator. Context Precision & Recall optionally use ground truth for more accurate measurement. This makes RAGAS practical for production evaluation where labelled data is scarce.
What Each Score Tells You — Failure Mode Map
🔴
Low Faithfulness → Hallucination
Faithfulness < 0.5
›
Symptom
Answer contains facts that don't appear in any retrieved chunk. Model is "free-associating" beyond the context.
Fix
Stronger system prompt ("Only answer using the provided context"). Use smaller, more focused models. Add citation enforcement.
🟡
Low Answer Relevancy → Off-Topic Answer
AR < 0.6
›
Symptom
Model returns a factually correct, grounded answer but doesn't actually answer the question asked.
Fix
Improve question understanding in prompt. Add answer format constraints. Use query rewriting to clarify intent before retrieval.
🟠
Low Context Precision → Noisy Retrieval
CP < 0.6
›
Symptom
Top retrieved chunks are mostly irrelevant. The relevant chunk exists but is ranked position 4 or 5, diluting context quality.
Fix
Add cross-encoder re-ranking layer. Use hybrid retrieval (dense + sparse). Tune chunk size to reduce noise.
🔵
Low Context Recall → Missing Information
CR < 0.6
›
Symptom
Key facts needed to answer the question are not present in the retrieved chunks. Retriever misses relevant documents entirely.
Fix
Increase top-k. Use multi-query retrieval (generate 3–5 query variants). Improve chunking strategy to avoid splitting related content.
