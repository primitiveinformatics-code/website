Layer 2 â€” Input Sanitisation
The prompt has passed authentication but now faces deep inspection for injection patterns, malicious content, and sensitive data before reaching the model.

Injection Classifier
A fast ML classifier (e.g. fine-tuned DistilBERT) labels inputs as benign or injected. High confidence injections are blocked; uncertain ones are flagged for review.

Named entity recognition strips SSNs, credit card numbers, and email addresses from inputs before they enter context â€” preventing accidental memorisation.

Each agent instance receives only the tools its task requires. Tool grants are scoped to the session and expire after task completion.
