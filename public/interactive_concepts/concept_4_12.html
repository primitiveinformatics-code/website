Query → Strategy Matcher
Pick a Query Type — Get the Right Strategy
Different query patterns demand different retrieval approaches
✅ Recommended: Dense Retrieval
Semantic question about a concept — no exact keywords needed. Dense embeddings capture "what is" / "explain" intent well. BM25 would miss paraphrases like "how does the attention mechanism work".
✅ Recommended: Sparse (BM25)
Exact identifier "ERR-4021" — this is a keyword match problem. Dense retrieval would retrieve semantically similar errors but might miss the exact code. BM25 excels at exact term matching.
✅ Recommended: Hybrid Retrieval
Comparative query needs both semantic understanding (concepts) and exact term matching (model names). Hybrid fuses dense + BM25 scores for the best of both worlds. Use RRF fusion.
✅ Recommended: Multi-Vector
Long document with multiple topics — index section summaries separately from full content. Retrieve the relevant summary first, then fetch the full section. Avoids "lost in the middle" with large docs.
✅ Recommended: Contextual Retrieval
Section reference query — the chunk "section 3.2" loses meaning without knowing what document it's in. Contextual retrieval prepends document context to each chunk before embedding, making isolated chunks meaningful.
