Tell the agent WHEN to use each tool â€” not just that they exist. Without guidance, agents either under-use or over-use tools.

ðŸ§  Chain-of-Thought Guidance High Impact
â–¼

Instruct the agent to reason step-by-step before acting. This dramatically improves accuracy on multi-step tasks and reduces hallucinated tool calls.

REASONING PROCESS:
Before calling any tool, think through:
1. What do I already know? (check context first)
2. What do I need to find out?
3. Which tool is best suited for this?
4. What could go wrong with this tool call?

After receiving tool results:
5. Does this answer the question fully?
6. Do I need another tool, or can I respond now?

Think step-by-step. Do NOT skip steps.
ðŸ Termination Conditions Critical
â–¼

Without explicit stopping rules, agents can loop indefinitely. Define DONE conditions clearly to prevent infinite tool call loops.

TERMINATION RULES:
STOP and respond to the user when:
- You have a complete answer with evidence
- You have called the same tool 3 times without progress
- You have made 10 total tool calls in this turn
- You encounter an error you cannot recover from

NEVER:
- Call tools in a loop hoping for different results
- Continue after 10 tool calls without asking the user
- Proceed if you're unsure whether action is reversible
