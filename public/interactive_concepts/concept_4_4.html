Map-Reduce Pattern

Fan-out parallel execution → fan-in aggregation — the fastest way to process large workloads with agents

The Core Idea

"Split a big task into independent sub-tasks (MAP), process them all in parallel with specialized agents, then combine the results into a single answer (REDUCE)."

✂️ Decompose

A dispatcher breaks the input into N independent chunks — by document, by question, by data shard.

⚡ Parallelize (MAP)

N mapper agents process their chunks simultaneously. Total time ≈ slowest mapper, not sum of all.

🔀 Aggregate (REDUCE)

A reducer collects all mapper outputs and synthesizes a final, coherent answer.

📈 Linear Speedup

Processing 10 documents with 10 agents takes roughly the same time as processing 1 document with 1 agent.

Analysing 50 Research Papers Simultaneously

Map: Each mapper receives one paper and extracts key findings, methodology, and limitations. Reduce: The reducer synthesizes cross-paper themes, identifies contradictions, and writes a literature review. Speed gain: 50x faster than sequential processing.

import asyncio async def analyse_paper(paper: str) -> dict: """Mapper: extract findings from one paper.""" result = await llm.complete( f"Extract findings, methodology, limitations from:\n{paper}" ) return parse_structured(result) async def map_reduce_papers(papers: list[str]) -> str: # MAP — all papers in parallel mapper_tasks = [analyse_paper(p) for p in papers] map_results = await asyncio.gather(*mapper_tasks) # REDUCE — synthesise combined = json.dumps(map_results, indent=2) synthesis = await llm.complete( f"Synthesise these paper analyses into a literature review:\n{combined}" ) return synthesis

Answering 20 Questions from a Knowledge Base

Map: Each mapper gets one question, retrieves relevant context from the vector DB, and generates an answer. Reduce: Answers are merged into a FAQ document. Total time ≈ single question latency.

async def answer_question(q: str, kb: VectorDB) -> dict: """Mapper: answer one question using RAG.""" context = kb.retrieve(q, top_k=5) answer = await llm.complete( f"Using this context:\n{context}\n\nAnswer: {q}" ) return {"question": q, "answer": answer, "sources": context} async def build_faq(questions: list[str], kb: VectorDB) -> str: # MAP — answer all questions concurrently answers = await asyncio.gather(*[answer_question(q, kb) for q in questions]) # REDUCE — format as FAQ faq_prompt = "Format these Q&A pairs into a structured FAQ:\n" + json.dumps(answers) return await llm.complete(faq_prompt)

Searching Multiple Data Sources in Parallel

Map: Specialized agents search different sources — web, internal docs, code repos, databases — simultaneously. Reduce: Deduplication and ranking agent merges findings by relevance.

async def search_web(query: str) -> list: ... async def search_docs(query: str) -> list: ... async def search_codebase(query: str) -> list: ... async def search_slack(query: str) -> list: ... async def parallel_search(query: str) -> str: # MAP — search all sources simultaneously results = await asyncio.gather( search_web(query), search_docs(query), search_codebase(query), search_slack(query), return_exceptions=True # don't fail if one source is down ) # Filter failed searches valid = [r for r in results if not isinstance(r, Exception)] # REDUCE — deduplicate and rank deduped = deduplicate(valid) return await llm.complete(f"Rank by relevance for '{query}':\n{deduped}")

Validating 1,000 Data Records

Map: Batch the 1,000 records into 10 chunks of 100. Each mapper validates its batch. Reduce: Collect all validation errors, deduplicate, and generate a quality report.

async def validate_batch(records: list[dict]) -> list[dict]: """Mapper: validate a batch of records.""" errors = [] for rec in records: issues = await llm.complete( f"Validate this record against schema. Return JSON errors:\n{rec}" ) if issues: errors.append({"record": rec["id"], "issues": issues}) return errors async def validate_all(records: list[dict], batch_size=100) -> str: # Split into batches batches = [records[i:i+batch_size] for i in range(0, len(records), batch_size)] # MAP — validate batches in parallel batch_errors = await asyncio.gather(*[validate_batch(b) for b in batches]) # REDUCE — aggregate errors all_errors = [e for batch in batch_errors for e in batch] return f"Found {len(all_errors)} validation errors across {len(records)} records.\n{all_errors}"

Strengths & Limitations

✅ Strengths

  • Massive parallelism — linear speedup
  • Predictable structure — easy to reason about
  • Individual mapper failures don't kill the job
  • Easy to add more mappers as load grows
  • Natural fit for batch workloads
  • Deterministic — same input → same structure

⚠️ Limitations

  • Tasks must be decomposable into independent chunks
  • Reducer can become a bottleneck with many mappers
  • Context windows limit reducer input size
  • Not suitable for sequential, dependent tasks
  • Overhead if N is small (dispatcher + reducer cost)
  • Reducer LLM may lose detail from large inputs
