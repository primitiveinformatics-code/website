Embeddings: Meaning as Numbers

How text is converted into dense vectors, why cosine similarity works, and which embedding model to pick for your RAG system.

What Are Embeddings?
The core idea: An embedding model reads a piece of text and outputs a list of floating-point numbers (a vector). Texts with similar meaning produce vectors that point in similar directions in high-dimensional space. This transforms the fuzzy problem of "semantic similarity" into a precise mathematical operation: cosine similarity.

Embedding in Practice
from openai import OpenAI
import numpy as np

client = OpenAI()

def embed(texts: list[str]) -> list[list[float]]:
    # Batch embedding — much cheaper than one call per text
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=texts,
        # Matryoshka: truncate to smaller dims for speed
        dimensions=512  # optional: reduce from 1536 → 512
    )
    return [d.embedding for d in response.data]

def cosine_similarity(a: list[float], b: list[float]) -> float:
    a, b = np.array(a), np.array(b)
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

# In RAG: embed query and find nearest neighbours
query_vec = embed(["How do I reset my password?"])[0]
# Then pass to vector DB for ANN search
results = vector_db.query(vector=query_vec, top_k=5)
