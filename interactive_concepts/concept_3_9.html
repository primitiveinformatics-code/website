Common Layer Mistakes

🎭

Missing Identity (Layer 1)

Agent has no defined role — behaves like a general chatbot, gives overly broad answers outside its domain.

Fix: Always start with a clear professional role + context sentence.
🚧

No Constraints (Layer 3)

Agent will attempt anything asked — sends emails without confirmation, deletes data, accesses unauthorized resources.

Fix: Explicit NEVER/ALWAYS rules. Most critical layer to get right.
📐

Missing Output Format (Layer 5)

Agent returns free-form text. Downstream parsing breaks. Pipeline fails silently or crashes with JSON decode errors.

Fix: Specify exact JSON schema. Add "never wrap in markdown" if needed.
🏁

No Fallback Rules (Layer 7)

Agent hallucinates when it can't find information, or loops indefinitely trying different tools before giving up.

Fix: Define explicit "I don't know" and max-retry behaviors.
